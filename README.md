# CSE240 — Intro to Programming Languages

Homework from CSE240, which jumps around a bunch of different languages/paradigms instead of sticking to one — C, C++, Prolog, and Racket.

## Assignments

- `cse240hw1` — basic C exercises, some debugging
- `cse240hw2` — C macros vs. regular functions, comparing `#define` macros to equivalent functions
- `cse240hw3` — pointers and memory in C
- `cse240hw4` — C++, a `Patient` class exercise (add/display/sort/find patients)
- `cse240hw5` — Prolog, family tree and meal-planning queries
- `cse240hw6` — Prolog, more logic programming
- `cse240hw7` — the same "blurb" pattern-recognition exercise done in both C++ and Racket
- `cse240hw8` — C++, multi-class OOP (`Container`, `Room`, and some character classes)
- `cse240hw9` — Racket, functional programming exercise
- `cse240extraCredit` — Racket, extra credit blurb pattern-recognition

## Languages

C, C++, Prolog, Racket
